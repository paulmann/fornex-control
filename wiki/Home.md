# Fornex Control

**Панель для DNS-зон Fornex: план → применение → снимок зоны перед каждой записью.**

Эта вики — подробное руководство: зачем панель нужна, как её поставить, как устроены правила
работы с зоной и что делать, когда что-то не работает. Короткое описание и установка в одну
страницу — в [README](https://github.com/paulmann/fornex-control).

## Три правила, которые объясняют всё остальное

1. **Сначала план, потом запись.** Любое изменение зоны сначала показывается планом: что
   создать, что изменить, что пропустить, где конфликт.
2. **Снимок до записи.** Перед каждым изменением зона сохраняется как BIND-файл и JSON с
   идентификаторами записей.
3. **Удаление только по `id`.** Ни масок, ни «все TXT с таким префиксом» — ошибка в шаблоне
   в зоне не видна до первого письма, которое не дойдёт.

## Что панель не делает

- Не хранит копию зоны: она читается из Fornex API при каждом запросе.
- Не трогает `SOA` и `NS` — они держат зону.
- Не ослабляет DMARC и не выбрасывает чужие механизмы SPF.
- Не печатает ключ API и пароль: только имя, маску и отпечаток.
